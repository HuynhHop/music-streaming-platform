# 🎵 Music Streaming Platform

A web application that allows users to listen to music online,
create personal profile, interact with other users, manage playlist,....

## 📸 Screenshots
![Home](images/image1.png)

## 🚀 Features
- Stream music
- Search songs
- Create playlists
- Like and share songs

## 🛠 Tech Stack
- React
- Node.js
- Express
- MongoDB

## ⚙️ Installation

git clone https://github.com/HuynhHop/music-streaming-platform.git
npm install
npm start
